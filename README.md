# JavaScript 1 · Lista de questões

São **15 questões curtas**, em ordem. Cada uma usa o que você aprendeu na anterior, então faça na sequência.

## Como funciona

Cada questão tem dois arquivos com o mesmo número:

```
01.html   ← abra no navegador: mostra o enunciado
01.js     ← escreva o seu código aqui
```

1. Abra a pasta no VS Code e o `index.html` no navegador.
2. Clique na questão. Abra o console: **F12** e depois a aba **Console**.
3. Escreva o código no `.js` da questão, salve e recarregue a página (**F5**).
4. Compare o que apareceu no console com a **saída esperada**, que está no começo do próprio `.js`.

Não precisa mexer nos arquivos `.html`.
